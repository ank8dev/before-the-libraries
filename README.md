# Before the Libraries

15 small Python exercises. They prepare you for NumPy, pandas, scikit-learn and PyTorch.
You write simple versions of library ideas by hand. Then the real library feels clear.

**Progress: 0/15** (change this number yourself)

Site: https://ank8dev.github.io/before-the-libraries/

## How to use it
**On the site:** each exercise has an editor. Press *Run example* to see pictures of the input and the output. Press *Check my code* to run all checks. Python runs inside your browser (Pyodide, loaded from a CDN). Your code and progress are saved in your browser only.

**On your computer:**
1. Open the site. Pick an exercise. Read the task.
2. Answer the "Predict first" question before you run anything.
3. Open `exercises/01_add_vectors.py`. Write your code in the stub (replace `pass`).
4. Run it: `python3 exercises/01_add_vectors.py`
5. If all checks pass, you see `All checks passed`. If not, read the failed `assert`.
6. Do not edit the "Checks" part.

Only the standard library is used. Python 3 is enough.

## The 15 exercises
- Numbers: add_vectors, dot, shape and transpose, flatten and reshape, scale_0_1
- Text: tokenize, top_words, vocab, bigrams, generate
- Evaluating: accuracy and confusion counts, train_test_split, batches
- Classes: Dataset, NearestNeighbor

There is no neuron training here. That is a separate project.
